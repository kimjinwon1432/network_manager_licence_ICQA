13. 라우터의 serial 2/0에 프레밍릴레이 dlci17로 설정 및 저장
라우터1 <-> 라우터2 (S1/0 : 192.168.1.0/24)
라우터2 <-> 라우터3 (S2/0 : 192.168.2.0/24)
* DLCI: Data Link COnnection Ideneifier, Frame Relay에서 가상회선을 식별하는 번호
en
conf t
int Serail2/0
encapsulation frame-relay // Frame-relay를 사용하겠다는 의미
frame-relay interface-dlci 17 //DLCI는 16부터 1007까지 사용 가능
~~~ Data link connection Indentifier // 이 포트의 DLCI는 17이라는 의미
no shut // 활성화
exit
exit
copy r s

19. 홉수가 15 이하인 중/소규모 네트워크 구성할거임. router1의 ripv2 라우팅 설정하시오. 단 pc의 gw ip 주소는 1번째 주소
pc3(192.168.10.10) ---- router1(s0/3/0 ip: 10.10.10.10) --- RIPv2 ----- ROUTER2(s0/3/0 ip: 10.10.10.20) ----- pc4(192.168.11.20)
en
conf t
router ip
version 2
network 10.10.10.10
network 192.168.10.1
no auto-summary // 거리 벡터 방식만 적용되고 자동축약은 안 한다는 뜻
exit
copy r s
20. 대규모 네트워크에서, 연결속도 기준(링크상태방식) 계산 하여 동적으로 라우팅 구성하고자함. router2의 라우팅 설정하라. pc의 gw주소는 1번째 주소, process 번호와 area는 1로함
pc3(192.18.10.10) - router1(10.10.10.10) ---- router2(ip: 10.10.10.20) - pc4(192.168.11.20)
en
conf t
router ospf 1
network 10.10.10.20 0.0.0.0 area 1
network 192.168.11.1 0.0.0.0 area 1
exit
exit
copy r s
